# CodeMorph Agent 🚀

An AI-powered Codebase Migration Agent built with **Langflow**, **LangChain**, and **Google Generative AI**. 

## 📌 Project Overview
CodeMorph Agent automates legacy code refactoring into modern, idiomatic Python 3.12 syntax. It automatically handles structural transformations (e.g., converting legacy print statements, updating string formatting to PEP 498 f-strings, adding PEP 585/604 type annotations) while generating clear explanations of key changes.

## 🛠 Tech Stack
* **Orchestration:** Langflow (Visual DAG workflow) & LangChain
* **LLM Engine:** Google Generative AI (Gemini Free Tier API)
* **Target Standards:** Modern Python 3.12 (PEP 498, PEP 585, PEP 604)

## 🚀 Key Features
* **Automatic Refactoring:** Upgrades legacy Python syntax to modern standards.
* **Type Annotation:** Injects static typing and union annotations.
* **Semantic Parity:** Wraps dictionary views and modified built-in behaviors to maintain execution correctness.
* **Refactoring Summaries:** Provides line-by-line documentation for code modifications.
